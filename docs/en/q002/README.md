# Question 002: The operation of counting the number of characters in a given string

---

We are given a string and asked to determine, separately for each character, how many times each character appears.
Answer:
We use a map with a key type of char and a value type of int or uint. We iterate over the characters of the string one by one, access the corresponding key in the map, and increment its value by one. Finally, we iterate over the keys of the map and print each key along with its value as the computed output.
Note:
For the sake of simplicity, the code below has been generated by Alibaba’s Qwen AI bot

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    std::string input;
    std::cout << "please enter a string: ";
    std::getline(std::cin, input); // for support including spaces and tabs in input string

    std::unordered_map<char, int> charCount;

    // counting the characters
    for (char c : input) {
        charCount[c]++;
    }

    // print the results
    std::cout << "\nprint the results:\n";
    for (const auto& pair : charCount) {
        // printing control charcters
        if (pair.first == '\n') {
            std::cout << "'\\n': " << pair.second << '\n';
        } else if (pair.first == '\t') {
            std::cout << "'\\t': " << pair.second << '\n';
        } else if (pair.first == ' ') {
            std::cout << "' ': " << pair.second << '\n';
        } else {
            std::cout << "'" << pair.first << "': " << pair.second << '\n';
        }
    }

    return 0;
}
```
## Important Notes

- `std::getline` is used to read the entire line, including spaces and special characters.

- `std::unordered_map<char, int>` is an efficient choice for storing the count of each character, providing average `O(1)` access time.  
  The reason for not using `std::map` is that the alphabetical ordering of keys is not important in this example.  
  `std::map`, which is typically implemented using a balanced BST (**Red-Black Tree**), has lower performance overhead compared to `std::unordered_map`, whereas `std::unordered_map`, which is based on a **Hash Table**, offers better runtime performance.  
  However, it does not preserve any order when iterating over the keys, which is not an issue in this case.

- Special characters such as space, tab (`\t`), and newline (`\n`) are printed in a human-readable form.

```output
please enter a string:  سلام دنیا
تعداد تکرار هر کاراکتر:
'س': 1
'ل': 1
'ا': 2
'م': 1
' ': 1
'د': 1
'ن': 1
'ی': 1
```
If you need to process Unicode strings (such as Persian), this program will work correctly as long as your compiler and terminal support UTF-8—because char in C++ can be used for UTF-8 byte processing. However, for more advanced Unicode handling, it is better to use std::wstring or dedicated libraries. For simple counting of UTF-8 bytes, though, this approach is sufficient
