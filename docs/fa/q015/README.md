# سوال 014:  یافتن بلندترین زیررشته مشترک بین N رشته با طول و کاراکترهای نامشخص - یافتن تمام زیررشته های مشترک بین N رشته با طول و کاراکترهای نامشخص

فرض کنید N رشته را به شما می دهند و از شما می خواهند بلندترین زیر رشته مشترک بین آنها را بیابید!
می توان در سوالی مشابه از شما بخواهند تمام زیر رشته های مشترک بین N رشته مختلفی را که می توانند هر طولی داشته باشند و تنوع کاراکترهایشان در اختیار ورودی کاربر باشد را مشخص کنید!
توضیح زیر رشته در سوال 13 از این سری سوالات داده شده است!
در مورد یافتن زیر رشته مشترک چند رشته، باید در نظر بگیریم که این زیر رشته مشترک مسلما طولی مساوی یا کوچکتر از طول کوتاه ترین رشته در میان تمام N رشته دارد! لذا باید از میان تمام N رشته، رشته ای را که کوتاهترین طول را دارد را انتخاب کنیم و محاسبات اصلی را حول آن شکل دهیم!
