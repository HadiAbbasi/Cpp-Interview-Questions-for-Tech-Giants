# سوال 001:  عملیات Swap دو متغیر عددی بدون متغیر واسط tmp

---

دو متغیر عددی داریم و می خواهیم بدون تعریف متغیر واسطه، اعداد آنها را با هم جایگزین کنیم! راهکار شما چیست؟ با فرض اینکه جمع دو عدد باعث سرریز نشود، روش معروف این کار اینست! اگر فرض کنیم دو متغیر A و B را داشته باشیم، و مقدار داخل A برابر Δ (مثلث) و عدد داخل متغیر B برابر # (مربع) باشد
