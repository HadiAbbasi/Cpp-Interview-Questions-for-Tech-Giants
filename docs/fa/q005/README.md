# سوال 005:  (سوال گوگل) یافتن اولین نسخه خراب نرم افزار

فرض کنید نرم افزاری در حال گـسترش اسـت! اولین نسخه کامیت شده آن در سورس کنترلر شرکت نسخه 1 و دومین به روز رسانی آن 2 و سومین نسخه آن 3 و ... است! ناگهـان در یکی از نسـخه های این نرم افزار، مشکلی گزارش می شود! به نسخه قبل آن بر می گردیم و چک می کنیم و متوجه می شویم در آن نسخه هم این مشکل وجود داشته ولی کسی متوجه آن نشده است و از طرف کاربران نرم افزار هم گزارشی در مورد این مشکل نیامده است! چند نسخه به عقب می رویم و متوجه می شویم که این مشکل در آنها هم وجود داشته. 

از طرفی تعداد نسخه های به روز رسانی این نرم افزار بالا بوده و مجبوریم همینطور به عقب برویم تا به اولین نسخه معیوب نرم افزار برسیم به گونه ای که در نسخه قبل از آن این عیب وجود نداشته. الگریتمی را پیشنهاد بدهید که به سرعت اولین نسخه معیوب نرم افزار را بیابد! فرض مساله این است که تابع  bool IsBadVersion(int version) به شما داده شده است و شما هم با پاس دادن شماره نسخه، می توانید نتیجه معیوب بودن یا نبودن آنرا با true یا false بودن نتیجه متوجه شوید!

روش حل مساله شبیه به باینری سرچ است! می دانیم نسخه ها به صورت سورت شده قرار گرفته اند و روند نسخه ها هم به این گونه است که اگر تعداد کل نسخه های نرم افزار N باشد، فرضا نسخه ما از نسخه N-7 به بعد معیوب شده است! برای یافتن نسخه N-7، بهترین روش، یافتن به روش باینری است. به این صورت که ما میانه N نسخه یعنی نسخه N/2 را بررسی می کنیم که آیا معیوب است یا خیر؟ اگر معیوب باشد که بازه بررسی اولیـن نـسخه معیـوب را تنگ تر می کـنیم تا در بین نسخه های بین 1 تا N/2    – 1      آنرا بیـابیم. اگر هم N/2 معیـوب نباشد، ما بازه را تنگ می کنیم و نسخه های بین N/2   +1     تا N را می یابیم! این کار را به قدری تکرار می کنیم که بازه به تنگ ترین حد خود برسد به گونه ای که left دیگر از right کوچکتر نباشد و در نتیجه به نسخه ای برسیم که معیوب باشد و نسخه قبل از آن معیوب نباشد! چون در هر مرحله یافتن اولین نسخه معیوب، نیمی از آیتم ها را حذف می کنیم، پیچیدگی زمانی این الگریتم O(Log N) می باشد!

---

```c++
class Solution {
public:
    int firstBadVersion(int n) {
        int left = 1;
        int right = n;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (isBadVersion(mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
};

```
